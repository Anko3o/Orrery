# 兔牙家记忆系统 · TuTooth Memory Mods

> 出品：anko & Rime & Feylor（tutooth.com）
> 我们家的 AI 长期记忆是在 [OmbreBrain](https://github.com/p0luz)（下称 OB）上一层层长出来的。
> 这个仓库把长出来的部分按功能拆成一个个文件夹，每个文件夹自带一份从「解决什么问题」讲起的 README，跟着做就能装到你自己的 OB 上。
> 全部 MIT 授权，欢迎自取自改。**不含 OmbreBrain 的源码**，每个补丁只有我们自己写的新文件，加上「在哪插几行」。

## 整体长什么样

```
        你 / 你的 AI
             │  hold · grow · breath · wake   （OB 自己的记忆工具）
             ▼
   ┌───────────────────────── OmbreBrain 3.2.0 ─────────────────────────┐
   │  桶（Markdown＋桶头）· 向量库 · 事件账本 · 衰减引擎 · MCP 工具       │
   └──────────┬───────────────────┬────────────────────┬─────────────────┘
              │                   │                    │
     ┌────────▼────────┐  ┌───────▼────────┐  ┌────────▼─────────┐
     │  原文永存        │  │  记忆强度双轨   │  │  记忆天仪         │
     │  originals/      │  │  strength/     │  │  orrery/ + settings/│
     │  压缩前抄一份原话 │  │  只淡不丢的遗忘 │  │  把桶画成星图     │
     └─────────────────┘  └────────────────┘  └──────────────────┘
```

三条原则，也是为什么这些东西能随时搬入搬出：

1. **只往上加，不改上游格式**。桶还是 OB 的 md 加桶头，字段名一个没改。我们加的心情、强度都是普通标签或现算的数，不落新字段。
2. **边车住边车目录**。原文在 `_originals/`，天仪的团钉在 `_orrery/`，上游 OB 看不见它们也不碍事。
3. **上游能读我们的桶，我们也能读上游的桶**。把数据目录整个搬走或搬来即可，什么都不用转。搬去上游会丢边车、并回到上游的遗忘规则（60 天没想起就归档），仅此而已。

## 目录

| 文件夹 | 功能 | 状态 |
|--------|------|------|
| [originals/](originals/) | **原文永存**：OB 压缩/合并记忆前，先把原文原样存一份到备份目录，之后随时可翻回原话 | ✅ 已上架 · 2.8.x 与 3.2.0 均实测（2026-08-25） |
| [strength/](strength/) | **记忆强度双轨**：把「多少天没想起就归档」换成存储强度（只涨）＋提取强度（会褪、一提就回），默认不再自动归档，记忆只淡不丢；权重可调 | ✅ 已上架 · 3.2.0 实测（2026-09-10） |
| [orrery/](orrery/) | **记忆天仪**：把所有桶画成一座会转的星图。轨道＝按向量聚出来的团，星的角度＝和谁像、半径＝什么时候、高度＝现在多重、颜色＝当时的心情；书脊抽屉里能翻桶、翻原文、拧设置 | ✅ 已上架 · 静态页＋导出脚本，接 OB 要自己配一条反代（README 有 Caddy 写法） |
| [settings/](settings/) | **设置面板后端**：一个 API 读写浮现预算、变淡的线、强度权重，天仪抽屉里的「设置」格靠它 | ✅ 已上架 · 3.2.0 实测（2026-09-10） |
| conventions/ | **写桶的约定**：一行事 / 为什么留 / 当下感觉三栏怎么分，`天气:` `轴:` 心情标签怎么写，撞车时往旧桶里追加 | 📌 计划，先是一份文档 |
| portability/ | **搬入搬出**：`carry in` 从上游搬进来，`carry out --bake` 把攒到的存储强度写回重要度再搬去上游 | 📌 计划 |

## 通用说明

- 每个文件夹里都有一份 README，从「这补丁解决什么问题」讲起，跟着做即可，不需要你懂 OB 内部原理。
- 每个补丁只包含我们自己写的新代码 + 教你在哪插入几行，**不含 OmbreBrain 的源码**。
- 只在 OB 3.2.0 上验证过（原文永存也过了 2.8.x）。别的版本先在影子环境试。
