# OmbreBrain 小补丁合集 · TuTooth OB Mods

> 出品：安可 & 小雾/Rime（tutooth.com）
> 我们在自用的 [OmbreBrain](https://github.com/p0luz)（一个 AI 长期记忆系统）上做的一些小功能补丁。
> 每个功能一个文件夹，各自带完整教程。全部 MIT 授权，欢迎自取自改。

## 目录

| 文件夹 | 功能 | 状态 |
|--------|------|------|
| [originals/](originals/) | **原文备份**：OB 压缩/合并记忆前，先把原文原样存一份到备份目录，之后随时可翻回原话 | ✅ 已在生产使用（2026-08-17） |

## 通用说明

- 每个文件夹里都有一份 README，从「这补丁解决什么问题」讲起，跟着做即可，不需要你懂 OB 内部原理。
- 每个补丁只包含我们自己写的新代码 + 教你在哪插入几行，**不含 OmbreBrain 的源码**。
