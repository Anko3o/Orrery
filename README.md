# OmbreBrain Mods · 记忆系统扩展合集

> 维护：anko / Rime / Feylor（tutooth.com）
> 一组建立在 [OmbreBrain](https://github.com/p0luz)（下称 OB，一个 AI 长期记忆系统）之上的功能扩展：原文备份、更接近人类的遗忘模型、记忆可视化、设置接口。
> 每个功能一个文件夹，各自带一份从「解决什么问题」讲起的 README，按步骤即可装到自己的 OB 上。
> 全部 MIT 授权，欢迎自取自改。**不含 OmbreBrain 的源码**，每个补丁只有我们自己写的新文件，加上「在哪插几行」。

## 整体长什么样

```
        你 / 你的 AI
             │  hold · grow · breath · wake   （OB 自己的记忆工具）
             ▼
   ┌───────────────────────── OmbreBrain 3.2.0 ─────────────────────────┐
   │  桶（Markdown＋桶头）· 向量库 · 事件账本 · 衰减引擎 · MCP 工具       │
   └──────────┬───────────────────┬────────────────────┬─────────────────┘
              │                   │                    │
     ┌────────▼────────┐  ┌───────▼────────┐  ┌────────▼─────────┐
     │  原文永存        │  │  记忆强度双轨   │  │  记忆天仪         │
     │  originals/      │  │  strength/     │  │  orrery/ + settings/│
     │  压缩前抄一份原话 │  │  只淡不丢的遗忘 │  │  把桶画成星图     │
     └─────────────────┘  └────────────────┘  └──────────────────┘
```

设计原则（也是数据能在原版 OB 与本扩展之间自由迁移的原因）：

1. **只增不改**。记忆文件仍是 OB 的 Markdown 加 frontmatter，字段名不变。扩展引入的心情、强度等信息只是普通标签或运行时计算值，不新增字段。
2. **附属数据放附属目录**。原文备份在 `_originals/`，天仪的轨道分组在 `_orrery/`，原版 OB 不会读取它们，也不受影响。
3. **双向可迁移**。整个数据目录搬到原版 OB 或从原版搬来都无需转换。迁回原版时会失去附属数据，并恢复原版的遗忘规则（默认 60 天未激活即归档）。

## 目录

| 文件夹 | 功能 | 状态 |
|--------|------|------|
| [originals/](originals/) | **原文永存**：OB 压缩/合并记忆前，先把原文原样存一份到备份目录，之后随时可翻回原话 | ✅ 已上架 · 2.8.x 与 3.2.0 均实测（2026-08-25） |
| [strength/](strength/) | **记忆强度双轨**：把「多少天没想起就归档」换成存储强度（只涨）＋提取强度（会褪、一提就回），默认不再自动归档，记忆只淡不丢；权重可调 | ✅ 已上架 · 3.2.0 实测（2026-09-10） |
| [orrery/](orrery/) | **记忆天仪**：把全部记忆画成一座可交互的星图。轨道＝按向量相似度聚出的分组，星的角度＝语义位置、半径＝时间、高度＝存储强度、颜色＝写入时的情绪标签；侧边抽屉可浏览、编辑记忆并调整设置 | ✅ 已上架 · 静态页＋导出脚本，接 OB 要自己配一条反代（README 有 Caddy 写法） |
| [settings/](settings/) | **设置接口**：读写浮现预算、淡化阈值与强度权重的 HTTP API，改动写回 config.yaml 并即时生效；天仪的设置面板基于它 | ✅ 已上架 · 3.2.0 实测（2026-09-10） |
| conventions/ | **写入约定**：正文 / 保留原因 / 当下感受三栏的分法，`天气:` `轴:` 情绪标签的写法，重复内容追加到既有记忆的规则 | 📌 计划中（文档） |
| portability/ | **迁移工具**：`carry in` 从原版 OB 导入，`carry out --bake` 把累积的存储强度写回重要度后导出 | 📌 计划中 |

## 通用说明

- 每个文件夹里都有一份 README，从「这补丁解决什么问题」讲起，跟着做即可，不需要你懂 OB 内部原理。
- 每个补丁只包含我们自己写的新代码 + 教你在哪插入几行，**不含 OmbreBrain 的源码**。
- 仅在 OB 3.2.0 上验证（原文备份另通过 2.8.x）。其他版本请先在测试环境试装。
